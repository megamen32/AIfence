# Правая панель Product Manager — синтетический макет

Открыть `index.html` в браузере. Это статический макет без сборки. Все значения внутри него синтетические и согласованы между четырьмя вкладками.

Принцип: сначала картинка, текст только подписи; каждый экран читается за 5 секунд.

## Экраны (hash-роуты)
- `#overview` — утро: полоса статуса (товары / отклонения / ₽ под угрозой / сломанные метрики), treemap по вендорам (площадь = выручка, цвет = отклонение от контроля), алерты по ₽/нед. Клик по KES → гипотеза.
- `#hypothesis` — заголовок + счётчик цены задержки (₽/нед и тикающая сумма с момента обнаружения), полоса жизненного цикла, график KES и контроля Astra Linux с маркером обновления, пунктиром расчётного движения KES по контролю и заливкой разрыва, пины доказательств на точках графика и карточки под графиком, шкала уверенности, задача аналитики с тегом «сгенерирована ИИ-помощником».
- `#path` — плёнка синтетических кадров прогона пути покупки, пропущенное событие на шаге добавления в корзину с красной рамкой, увеличенный кадр и «ждали / увидели».
- `#after` — карточка повторного замера, восстановленный индекс и сравнение до/после.

## Данные
Макет использует полностью синтетический пример с реальными каталожными названиями. Массивы заказов и контроля находятся в JavaScript внутри `index.html`. Все проценты, ₽/нед, площадь плиток и значения повторного замера считаются из этих массивов. Вкладки используют одну и ту же формулу сравнения средних четырёхнедельных окон.

Синтетические источники обозначены локаторами `synthetic-*`. Они не ссылаются на клиентские документы, номера кейсов или защищённые материалы.

## Реализация
Цвета — токены в `:root` (тёмная/светлая тема). Графики — inline SVG без библиотек; treemap — squarified в ~20 строках JS. Анимация: stroke-dashoffset линий + fade разрыва/пинов, отключается при prefers-reduced-motion.
