# Автоматический импорт на Mac

Watch Cases проверяет четыре входных файла Product Manager: книгу продуктовых данных, таблицу конкурентов, презентацию и ZIP интервью. Файлы остаются в проекте. Вход в штатный Airlock CLI должен принадлежать тому пользователю Mac, под которым работает launchd. Локальный Airlock доступен по `http://localhost:42080`.

Из каталога `/Users/user/AIfence` запустите

```sh
/usr/bin/python3 -B apps/product-manager/ops/watch_cases.py install
/usr/bin/python3 -B apps/product-manager/ops/watch_cases.py status
launchctl print "gui/$(id -u)/org.aifence.product-manager.watch"
```

После однократной установки служба автоматически загружается при последующих входах этого пользователя в macOS. Проект хранит определение в `.runtime/product-manager/watch/`. Стандартный каталог `~/Library/LaunchAgents/` содержит единственную ссылку `org.aifence.product-manager.watch.plist` на это определение. Повторная установка в прежнем сеансе сохраняет текущую службу. Для уже запущенной службы старого формата та же команда добавляет постоянную регистрацию. Файл другого владельца с таким именем сохраняется, установка сообщает о конфликте.

launchd запускает проверку при регистрации, изменении входных файлов или состава папки и каждые 10 800 секунд. macOS объединяет близкие события. Уснувший Mac проверяет данные при следующем запуске задания. Неизменные SHA-256 всех четырех файлов дают тихий выход с кодом 0. При обновлении скрипт проверяет временную копию входных файлов и вызывает штатный `sync_case.py`. Тот импортирует данные в приложение и открывает или находит гипотезу. Отправку задачи в локальный бэклог подтверждает человек. При ошибке launchd повторяет попытку с минимальным интервалом 300 секунд.

После успешного ответа Airlock файл `checkpoint.json` сохраняет подписи и квитанцию с ID снимка, гипотезы, версией и статусом. Права файлов ограничены владельцем. Более свежий снимок виден в разделе «Снимки данных». Если гипотеза с тем же ключом уже существует, она сохраняет исходную доказательную базу и решение человека. В этом случае `previous_case_pinned` имеет значение `true`: ID нового и закрепленного снимков доступны в квитанции. Чтобы сравнить наблюдения, откройте новый снимок из списка.

Для ручной проверки и диагностики в том же сеансе

```sh
/usr/bin/python3 -B apps/product-manager/ops/watch_cases.py check
tail -n 10 .runtime/product-manager/watch/errors.log
/usr/bin/python3 -B -m unittest discover -s apps/product-manager/ops -p test_watch_cases.py -v
```

Если CLI требует новый вход, авторизуйтесь в локальном Airlock штатным способом под своим пользователем. Следующая попытка подхватит измененные файлы. Если база самого Airlock была восстановлена из резервной копии, один раз запустите `apps/product-manager/sync_case.py` вручную, чтобы зарегистрировать текущий снимок. Остановить задание до следующего входа в macOS можно командой `launchctl bootout "gui/$(id -u)/org.aifence.product-manager.watch"`.

Для постоянного отключения после остановки убедитесь через `readlink ~/Library/LaunchAgents/org.aifence.product-manager.watch.plist`, что ссылка ведет на определение этого проекта. Удалите только эту ссылку. Журнал, подтвержденная версия и исходные файлы сохранятся.
