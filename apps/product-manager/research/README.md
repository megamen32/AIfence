# Исторические свидетельства для Product Manager

Из корня AIfence на Mac выполните

```sh
python3 apps/product-manager/research/import_case.py \
  --materials 'материалы/Материалы заказчика' \
  --output .runtime/product-manager/evidence.json
python3 -m unittest discover -s apps/product-manager/research -v
```

Импортер использует Python 3.9+ и стандартную библиотеку. Он обрабатывает книгу с данными продукта, конкурентную таблицу, два описательных слайда и три книги из архива интервью. Файл с доступом в личный кабинет, готовый разбор кейса и слайды с рекомендациями в анализ не входят. Имена файлов и печатные диапазоны листов сохраняются вместе с SHA-256 версии исходника. Содержимое клиентских файлов в репозиторий не кладут.

Программа выбирает релизы, в строке которых указаны индекс заказов и название семейства. Для каждого кандидата она оценивает относительное изменение среднего недельного индекса по полным неделям. При наличии хотя бы четырех недель с каждой стороны выбирается наиболее сильное зарегистрированное снижение. Неделя самого релиза исключена. Базовое окно содержит 13 недель, окно наблюдения идет со следующего понедельника до среза. Для сравнения сохраняется расчет с неполной последней неделей. При нескольких продуктах для сравнения передайте конкретный `--control`. Параметры `--product`, `--release`, `--baseline-from`, `--keyword` и повторяемый `--alias` позволяют воспроизвести другой выбранный вопрос на том же формате данных.

В выходном JSON находятся `schema_version=aifence.case.v1`, `source_policy=local_project_only`, `as_of` и массив `batches`. Каждый элемент массива соответствует `contracts/evidence-v1.schema.json`. Один источник `market` может встречаться несколько раз. Используйте все пачки. Папка назначения должна находиться за пределами исходников приложения. Файл создается атомарно с правами владельца. Импортируйте его только в закрытый локальный контур клиента.

Недельный индекс относится к самостоятельным заказам. Для сравнения приведены размер выборки, исходные ячейки и обе средние. При отсутствии событий корзины значение равно `null`. Отношение для Метрики вычисляется из сумм числителей и знаменателей по присутствующим дням каждого устройства. В рыночную таблицу входят строки, отмеченные источником как полностью сопоставимые. Ответы интервью отобраны по словам и отмечены на уровне бренда. У недатированных материалов период обозначает дату среза. Выход содержит только свидетельства. Гипотеза, критерий проверки и решение по бэклогу появляются в отдельной операции Product Manager.
