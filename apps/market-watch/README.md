# Market Watch
Native Airlock Agent SDK v0.11.0 app; Go collector runs in the same binary.
Tools: list_offers, refresh_market, market_changes. Native file storage,
CSV and native three-hour job. Currently configured sample pages, not whole
catalogs. `go tool air build` and official `go tool air deploy`.
Ask "Refresh KL4141RCEFS prices in all three stores, with sources".
