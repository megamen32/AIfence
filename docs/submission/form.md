# Текст заявки AIfence

Короткие формулировки для переноса в форму организатора.

| Поле | Текст |
| --- | --- |
| **Название** | AIfence |
| **Описание** | AI-помощник продакт-менеджера интернет-магазина: по обычному вопросу директора сам собирает рыночные и аналитические свидетельства, отделяет сигнал от причины и предлагает следующую проверку. |
| **Проблема** | При падении заказов команда вручную сводит Метрику, историю релизов, путь покупки и предложения конкурентов. Решение о скидке или доработке принимается поздно и может стоить маржи. |
| **Решение** | Market Watch и Metrika Analyst дают датированные наблюдения. Правая панель Product Manager ведёт директора по вкладкам «Утро», «Гипотеза KES», «Путь покупки» и «После релиза». Фоновый цикл сам закрепляет сигнал и доводит его до Redmine #8 с проверкой дублей, а Dion получает утреннюю сводку. |
| **Данные** | В видео используются seeded данные с явной меткой **ДЕМО**. Метрики и цены синтетические, чтобы воспроизводить показ без клиентских файлов. Названия и SKU взяты из публичного каталога, а наблюдения сохраняют источник, локатор и условия сопоставимости. |
| **Экономика** | В датасете KES измерено падение индекса самостоятельных заказов на 32,726%; абсолютные заказы, средний чек и маржа не раскрыты. В комплекте есть калькулятор позднего обнаружения и отдельный пример с явно указанными допущениями. |
| **Модель** | Фактический слот демо-Airlock: `omniroute`, `combo/airlock-personal-exec-terra61-safe`, Terra 6.1 с MiniMax failover; точный checkpoint и лицензия весов требуют подтверждения. |
| **Предыдущие наработки** | Airlock Enterprise — закрытая платформенная зависимость; AIfence — собственный код команды и документация. Открытые библиотеки и лицензии перечислены в [models-and-prior-work.md](models-and-prior-work.md). |
| **Стенд** | Владелецский Mac Airlock `http://localhost:42080`. Tunnel или приглашение жюри передаётся отдельно. Публичный стенд не используется. |
| **Исходники** | Репозиторий оставлен приватным по решению владельца; анонимная проверка GitHub ранее вернула HTTP 404. |
| **Качество** | Офлайн-сторож на запечатанной выборке v2: **11/22 попаданий, 0 ложных тревог; S14 — 0/6**. Чат Product Manager на Terra fast, dev30 prompt v4: **19/20 cause-first, 0 ложных тревог**. Это разные проверки; попадание не равно доказанной причинности. |
| **Кадры** | [PM-панель](../qa/pm-panel-27-11/01-hypothesis-kes-baseline.png), [сбор данных](../qa/scenes-27-11/01-data-collection.png), [цены конкурентов](../qa/scenes-27-11/02-competitor-prices.png), [карточка PM](../qa/scenes-27-11/03-product-manager-card.png), [Redmine #8](../qa/scenes-27-11/08-redmine-issue.png). |
| **Ограничения** | Результат не утверждает причинность без независимого доказательства и не выдаёт индекс заказов за рубли. Финальный SHA релиза подставляется перед подачей. |
