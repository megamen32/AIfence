# Текст заявки AIfence

Рабочие формулировки для переноса в форму. Названия и лимиты полей организатора пока не сверены.

| Поле | Текст |
| --- | --- |
| Название | **AIfence** |
| Краткое описание | Помощник продакт-менеджера интернет-магазина. Помогает понять, где продажи отклонились от обычного уровня, какие объяснения подтверждаются источниками и какую проверку имеет смысл поручить команде. |
| Проблема | Когда заказы падают, приходится вручную сводить аналитику, историю выпусков и предложения рынка. Преждевременное решение о цене или доработке может стоить времени и маржи. |
| Решение | Модули источников готовят наблюдения по рынку и веб-аналитике. Сценарий пользователя сохраняет их снимок в общем каталоге Airlock. Product Manager импортирует снимок и ведёт расследование от карточки гипотезы до проверки результата. Также поддерживается импорт ранее подготовленных снимков. Создание задачи требует отдельного подтверждения человека. |
| Данные | В конкурсном прогоне показатели и цены синтетические. Названия и SKU взяты из публичного каталога. Для сравнения в карточке остаются дата, ссылка и условия предложения. |
| Стенд | [aifence.bezrabotnyi.com](https://aifence.bezrabotnyi.com/). Для интерактивной проверки требуется приглашение в демонстрационное пространство. [Вход и развёртывание](deployment.md). |
| Экономика | Измерены время и токены двух синтетических QA-запросов. Стоимость финального прогона и финансовый эффект ожидают входных данных и подтверждения. [Замеры и расчёт](economics.md). |
| Модели и прежние наработки | [Состав, версии и лицензии](models-and-prior-work.md). |

## Перед заполнением обязательных полей

- **Видео.** После 22:00, freeze и отдельного допуска записать непрерывный дубль до 3:00 по итоговой таблице. Проверить ссылку из чистого профиля. [Сценарий](demo.md).
- **Репозиторий.** Получить решение владельца о версии для жюри и способе доступа, после этого указать URL и точный коммит конкурсной версии.
- **Стенд.** Проверить вход выданной учётной записью, основные приложения и доложить их фактический статус. Способ доступа передаётся отдельно от текста заявки.
- **Команда.** Вписать согласованные имена, роли и контакт. Сверить обязательные поля и лимиты с кабинетом организатора.
- **Результаты.** Заполнить по итоговой таблице. [Модель и SHA] · [подтверждено из всех] · [ложные тревоги] · [неоценённые] · [ограничения и источники]. При наличии полного замера указать время, токены и подтверждённую стоимость.
