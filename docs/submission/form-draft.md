# Текст заявки AIfence

| Поле | Текст |
| --- | --- |
| Название | AIfence |
| Краткое описание | Помощник продакт-менеджера интернет-магазина: собирает сигналы, связывает их с доказательствами и ведёт результат в Redmine и Dion. |
| Проблема | Ручная сверка заказов, аналитики, релизов и цен конкурентов задерживает решение по отклонению продаж. |
| Решение | Источники готовят наблюдения, Product Manager считает отклонения кодом, отображает доказательства и создаёт задачу с подтверждением. |
| Данные | Конкурсный прогон использует синтетические метрики и открытые названия продуктов и SKU. |
| Результат | Terra fast blind30: 18/20 правильных причин, 0/10 ложных тревог, медиана 112 секунд, 0 ошибок. |
| Улучшение | PR #18 и #19: правильная причина 4/20 → 14/20; ложные тревоги 7 → 1. |
| Экономика | $0.028 за кейс; период = `$0.028 × число кейсов × число вызовов модели`. [Расчёт](economics.md). |
| Стенд | `http://localhost:42080` |

Приложения: Market Watch, Metrika Analyst, Wordstat, Google Trends, Web Scraper и Product Manager. Интеграции Redmine, Dion и Baserow подключены через MCP.
