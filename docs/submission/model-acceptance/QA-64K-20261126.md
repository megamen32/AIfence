## Dedicated profile

Created the native Ollama alias gemma4:aifence-64k with:

    FROM gemma4:latest
    PARAMETER num_ctx 65536

The manifest reuses the exact existing model weight blob. Verified the alias
parameter, model capabilities, and discovery via the OpenAI endpoint from
server-100. The second full-window request established that the profile's
default context works through the OpenAI adapter, not merely the native API.

No Ollama/LiteLLM/queue restarts or default model changes were made. The
existing OmniRoute/LiteLLM aliases and the shared queue retain their 8192
limits. This new profile is not yet registered in the Airlock provider
catalog; a normal signed-in administrator must add it. Keep the original
model configured until the final product acceptance is complete. Register
gemma4:aifence-64k on the existing direct stand provider with context 65536,
then verify a complete synthetic app/chat request, actual usage, and vision
and tool capabilities before claiming final readiness. Do not change
workspace-wide defaults during another agent's active test.
