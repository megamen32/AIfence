# Модели, лицензии и предыдущие наработки

Состав и права нужно сверить с финальной сборкой перед сдачей. Записи о моделях разработки основаны на указании владельца; их провайдеры и условия здесь не установлены. Не размещать ключи, частные URL и договоры.
