## Архитектура и запуск

Короткая схема и команды запуска находятся в корневом [README.md](../../README.md).
Приложения разделены по независимой ценности: Market Watch собирает публичные
предложения, Metrika Analyst читает разрешённые метрики, Product Manager
единственным образом связывает доказательства в гипотезу. Workflow сохраняет
версионированный снимок в каталоге Airlock, а Product Manager импортирует его
или явно разрешённый исторический снимок. Числа считает код, а модель Terra
fast формулирует вывод в пределах источников.

Для локальной проверки:

```sh
./scripts/up
# затем открыть http://localhost:42080 и пройти штатную активацию
```

Для native M1 build/deploy используйте точный commit из интегрированного
`main`, [personal build](../../docs/personal-releases.md) и [deployment guide](deployment.md).
Секреты, токены и операторские приглашения в этот документ не копируются.

## Перед отправкой

1. После code freeze записать точный SHA интегрированного `main` и проверить,
   что он совпадает с собранным пакетом.
2. Прочитать `sol-stand/REPORT.md` и заменить текущий origin на точную tunnel
   ссылку, если стенд её выдаёт.
3. Взять из финальной QA-таблицы только подтверждённые результаты; не называть
   HTTP 200, нулевой счётчик токенов или отсутствие issue доказательством
   успешной приёмки.
4. Проверить MP4 через `ffprobe`, открыть ссылку в чистом браузере и передать
   приглашение в демонстрационное пространство отдельно от текста заявки.
