## Подход и архитектура

AIfence — автономный контур развития продукта для продакт-менеджера интернет-магазина. Источники данных готовят наблюдения по рынку и веб-аналитике. Product Manager считает отклонения кодом, формирует доказательства и связывает сигнал с задачей Redmine и сводкой Dion.

## Результаты измерения

Свежий blind30 на Terra fast: 18/20 правильных причин, 0/10 ложных тревог, медиана 112 секунд, 0 ошибок.

После PR #18 и #19: правильная причина 14/20 против 4/20 до исправления; ложные тревоги 1 против 7.

## Поставка

Стенд AIfence работает на Mac по адресу `http://localhost:42080`. Приложения используют Airlock v0.8.15 и Agents SDK v0.11.0. Код и данные конкурса находятся в приватном репозитории.
