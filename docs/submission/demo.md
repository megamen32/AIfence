## Перед записью

- Выбрать 3–5 кейсов по зафиксированным результатам. Для репетиции использовать локальные материалы и факты из завершённых проверок. Порядок проверки — сильная модель на Mac, затем freeze и финальный допуск для Gemma.
- После финального допуска проверить каждый маршрут в отдельном чистом контексте. В запись брать только область чата и панели. Профили, учётные данные, заказчицкие файлы и рабочие экраны остаются за кадром.
- Сохранить один проход без склеек длительностью 175 секунд. Озвучка повторяет фактические результаты. Проверить MP4 через `ffprobe` и просмотреть начальный кадр, переходы между чатами и финал.
