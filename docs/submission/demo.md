## Монтажные и доказательные правила

- Источники 1–4 берутся из `docs/qa/scenes-27-11/`; не пересобирать в кадре
  числа из макета или вручную нарисованных карточек.
- Перед записью сверить каждый кадр с финальной ревизией и итоговой таблицей
  КТ5. Если кадр снят со старой ревизии, на нём должна быть подпись
  «архивный снимок», а в основной демонстрации нужно заменить его.
- Для Redmine и Dion не показывать секреты, токены, cookies, адреса личных
  чатов или внутренние endpoint URL. ID задачи можно показывать только если он
  есть в разрешённом QA-отчёте.
- Не озвучивать причинность, которой нет в источниках. Если источник вернул
  `unavailable`, `no_alert` или `insufficient_data`, произнести этот статус и
  следующий способ проверки.
- Проверить MP4: `ffprobe` должен показать 175 секунд и звуковую дорожку;
  отдельно просмотреть начало, переходы и финальный кадр. Файл и метаданные
  остаются в защищённом `.runtime`.
