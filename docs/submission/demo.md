# Сценарий одного дубля, до трёх минут

Директор открывает Product Manager под демонстрационной учётной записью. Используйте разрешённые к показу данные. Для учебного прогона отметка «синтетические данные» должна быть видна с первого кадра.

| Время | Что происходит в кадре |
| --- | --- |
| 0:00–0:15 | В правой панели уже видна карта каналов. Покажите место сигнала и время, когда сторож его записал. Если подтверждена доставка письма, откройте карточку по ссылке из письма. |
| 0:15–0:45 | Директор пишет в чат «У нас после последнего релиза что-нибудь сломалось?». Оставьте в кадре, как панель переходит к выбранному агентом продукту. |
| 0:45–1:15 | Откройте выделенную точку. Покажите ряды продаж, с чем агент их сравнил, и где на графике находится релиз. Откройте ссылку на источник одного факта. |
| 1:15–1:50 | Покажите, до какого шага удалось дойти сегодня на компьютере и телефоне. По скриншоту виден интерфейс корзины, отправку события подтверждает сетевое наблюдение. Дайте зрителю прочитать статус исторической гипотезы. |
| 1:50–2:15 | Дождитесь предложения агента создать конкретную задачу. Только теперь директор отвечает «Да, заведите её». Откройте созданную задачу и покажите тег и критерий приёмки. |
| 2:15–2:40 | В отдельной явно подписанной учебной истории после исправления покажите контроль и результат замера. Цвет карточки должен соответствовать измеренному исходу. |
| 2:40–3:00 | Покажите недельный денежный сценарий с источниками входных чисел. Если данных для него нет, покажите пустые входы. Для стоимости работы агента используйте замеры именно этого запуска. |

Запись идёт непрерывно. Длинное ожидание можно ускорить, если это допускают условия конкурса. Любой шаг со статусом «нет данных» должен остаться видимым.
