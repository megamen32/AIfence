# Проверка сторожа в чате

26 ноября 2026 года в локальном Product Manager прошёл запрос к развёрнутому Metrika Analyst через обычный `run_js`. Использованы только встроенные учебные источники `fixtures/synthetic-watch.json` и `fixtures/synthetic-watch-context.json`.

Попросите проверить `demo_target` относительно `demo_control` по `orders_index` с 13 февраля по 5 марта 2023 года на срезе 3 марта. На неделе 13 февраля показатель остаётся в пределах порога. На неделе 20 февраля сторож обнаруживает падение на фоне стабильного контроля. На неделе 27 февраля ещё нет полного наблюдения, решение равно `null`. Ответ из чата совпал с тремя значениями штатного SDK-вызова `replay_signals`.

Из таблицы Airlock `runs` для этого запроса получены 32,03 секунды, 4 вызова модели, 53 884 входных и 1 756 выходных токенов. В этот замер входят запрос из чата и чтение сигнала. Создание карточки, проверка браузером и запуск на открытой модели требуют отдельных замеров.

В том же развёртывании сохранённый `run_js_file` отклонил обычный объект аргументов с ошибкой `executor does not support structured script args`. Обычный `run_js` успешно вызывает типизированные инструменты. Проверка установки файла в каталог сама по себе не подтверждает выполнение сценария.
